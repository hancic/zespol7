# zespol7

INSTRUKCJA OBSŁUGI
Program należy uruchomić komendą python main.py, nie ma potrzeby instalowania dodatkowych paczek.
By korzystać z już stworzonych kont użytkowników na potrzeby testów można zobaczyć listę loginów w pliku users.jsonl, hasła są takie same jak loginy.

OPIS PROGRAMU
Program umożliwia dodawanie, usuwanie i edytowanie przypomnień na swoim indywidualnym, chronionym hasłem koncie. Można rejestrować nowe konta oraz, po zalogowaniu, usunąć swoje konto. Użytkownik może wyświetlić listę swoich przypomnień, korzystając z różnych filtrów, by znaleźć pożądane informacje. Dostępne filtry to wyświetlenie wszystkich powiadomień, wyświetlenie powiadomień na dzisiaj, wyświetlenie powiadomień na następny tydzień, na następny miesiąc, na dany dzień, zaległych powiadomień, powiadomień z danej kategorii (istnieje możliwość wyświetlenia wszystkich kategorii stworzonych przez użytkownika, by nie trzeba było ich pamiętać) oraz wyszukania danej frazy w komentarzu.

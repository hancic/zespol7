# zespol7

INSTRUKCJA OBSŁUGI
Program należy uruchomić komendą python main.py, nie ma potrzeby instalowania dodatkowych paczek
By korzystać z już stworzonych kont użytkowników na potrzeby testów można zobaczyć listę loginów w pliku users.jsonl, hasła są takie same jak loginy

OPIS PROGRAMU
Program umożliwia dodawanie, usuwanie i edytowanie przypomnień na swoim indywidualnym, chronionym hasłem koncie. Użytkownik może wyświetlić listę swoich przypomnień, korzystając z różnych filtrów, by znaleźć pożądane informacje.
